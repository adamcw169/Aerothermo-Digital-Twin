# Contributing

Contributions should preserve the project's inert, non-operational scope and evidence-first approach.

1. Open an issue describing the context of use and affected requirement.
2. Add or update tests with the implementation.
3. Record new assumptions and data provenance.
4. Keep measured, synthetic and estimated quantities visibly distinct.
5. Do not add energetic-material, internal-ballistics, guidance or weapon-effect functionality.

A strong pull request explains the engineering decision supported, evidence generated, limitations introduced and reproducibility steps.
